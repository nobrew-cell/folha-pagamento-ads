================================================================================
                     SISTEMA DE FOLHA DE PAGAMENTO – v7.1
                             -- Guia de Uso --
================================================================================

Antes de qualquer coisa, um aviso tranquilizador:
    Voce nao precisa saber programar para usar este sistema.
    So precisa saber digitar e pressionar ENTER.

Este guia mostra o que aparece na tela e como o sistema se comporta.

================================================================================
                           --- INDICE RAPIDO ---
================================================================================

1. Como abrir o sistema
2. Primeiro acesso (ADM automatico)
3. Escolha do perfil (Funcionario / Administrador)
4. Menu principal (perfil comum)
5. Operacoes disponiveis
   * Cadastros (padrao, comissionado, producao)
   * Gerar folha de pagamento
   * Menu administrativo (ADM)
6. Menu ADM - manutencao e configuracoes
7. Exportar, importar, novo mes, editar, remover, reset
8. Configuracoes do sistema (salario base, teto, matricula)
9. Edicao em lote e dashboard analitico
10. Mensagens de erro mais comuns
11. Sair do sistema

================================================================================
 1. COMO ABRIR O SISTEMA
================================================================================

Recomendado: clique duas vezes no arquivo `executar.bat`
(Windows pode pedir confirmacao - clique em "Executar assim mesmo").

O sistema compila e abre sozinho. O menu aparece no terminal.

================================================================================
 2. PRIMEIRO ACESSO (nenhum dado cadastrado)
================================================================================

--------------------------------------------------------------------------------
Bem-vindo ao Sistema de Folha de Pagamento
--------------------------------------------------------------------------------

- Primeiro acesso detectado.
- Entrada automatica como ADMINISTRADOR.
- Pressione ENTER para continuar.

Nenhum funcionario cadastrado ainda.

Apos ENTER, o menu principal do ADM e exibido.

================================================================================
 3. ESCOLHA DO PERFIL (acessos seguintes)
================================================================================

--------------------------------------------------------------------------------
Como deseja acessar?
--------------------------------------------------------------------------------
[1] - Funcionario
[2] - Administrador

Opcao: >> 1   (ou 2)

Se digitar outro numero, o sistema repete a pergunta ate receber 1 ou 2.

================================================================================
 4. MENU PRINCIPAL (perfil FUNCIONARIO)
================================================================================

--------------------------------------------------------------------------------
FOLHA DE PAGAMENTO - Perfil: FUNCIONARIO
--------------------------------------------------------------------------------
[1] - Cadastrar Funcionario Padrao
[2] - Cadastrar Funcionario Comissionado
[3] - Cadastrar Funcionario de Producao
[4] - Gerar Folha de Pagamento
[0] - Sair
--------------------------------------------------------------------------------

No perfil ADMINISTRADOR, aparece uma opcao extra [5] - Menu ADM.

================================================================================
 5. OPERACOES DO MENU PRINCIPAL
================================================================================

--------------------------------------------------------------------------------
[1] - CADASTRAR FUNCIONARIO PADRAO
--------------------------------------------------------------------------------

Digite 0 a qualquer momento para cancelar.

Nome: >> Carlos Souza
Matricula: >> 1

-> [OK] Funcionario cadastrado com sucesso.

>> Validacoes comuns:

- Nome vazio: sistema pede novamente.
- Matricula ja existe: pede outra.
- Matricula nao numerica: pede numero valido.
- Matricula negativa ou zero: pede valor positivo (ou 0 para cancelar).
- Nome muito parecido com outro ja cadastrado: avisa e pergunta se deseja continuar.

Exemplo de aviso de nome semelhante:

   Atencao: nome semelhante ja cadastrado:
     Carlos Souza (matricula 1)
   Continuar mesmo assim? (S/N): >> S ou N

>> Controle de sequencia de matricula:

O sistema pode operar em dois modos (configuravel pelo ADM):

- FLEXIVEL (padrao): aceita qualquer matricula, mas avisa se houver numeros livres menores.
- RIGIDO: exige a proxima matricula na sequencia. Caso contrario, bloqueia e pede a correta.

Exemplo (modo FLEXIVEL):

   Matricula: >> 10
   [AVISO] Existem 2 matricula(s) livre(s) antes deste numero: [8, 9]
   Deseja continuar com a matricula 10? (S/N): >> S

Exemplo (modo RIGIDO):

   Matricula: >> 8
   [SEQUENCIA] Modo rigido: a proxima matricula esperada e 7.
   Digite outra matricula (ou 0 para cancelar): >> 7 -> OK.

>> Limite maximo de matricula (configuravel pelo ADM):

Se o limite for 10 e o usuario digitar 15:

   [LIMITE] Matricula 15 ultrapassa o limite maximo de 10.
   Digite outra matricula (ou 0 para cancelar):

--------------------------------------------------------------------------------
 [2] - CADASTRAR FUNCIONARIO COMISSIONADO
--------------------------------------------------------------------------------

Nome: >> Beatriz Alves
Matricula: >> 11
Total de vendas mensais (R$): >> 18000
Percentual de comissao (%): >> 5

-> [OK] Funcionario cadastrado.

>> Validacoes:

- Valores negativos: nao sao aceitos.
- Decimais podem usar virgula (ex: 26.130,41 ou 3,5).
- Digitar 0 no nome cancela o cadastro.

--------------------------------------------------------------------------------
 [3] - CADASTRAR FUNCIONARIO DE PRODUCAO
--------------------------------------------------------------------------------

Nome: >> Thiago Nunes
Matricula: >> 14
Pecas produzidas no mes: >> 300
Bonus por peca (R$ liquido): >> 5

-> [OK] Funcionario cadastrado.

>> Controle de teto de bonus:

- Salario base padrao: R$ 2.000,00
- Teto padrao: 200% do salario base (R$ 4.000,00)
- Se bonus total (pecas x valor) ultrapassar o teto, o cadastro e bloqueado.

Exemplo de bloqueio:

   Pecas: 300
   Bonus por peca: R$ 15,00
   -> Bonus total R$ 4.500,00 ultrapassa teto de R$ 4.000,00.
   Cadastro bloqueado. Consulte a diretoria.

--------------------------------------------------------------------------------
 [4] - GERAR FOLHA DE PAGAMENTO
--------------------------------------------------------------------------------

Exibe todos os funcionarios com seus respectivos salarios e componentes.

--------------------------------------------------------------------------------
FOLHA DE PAGAMENTO MENSAL - Total de funcionarios: 3
--------------------------------------------------------------------------------
Nome: Carlos Souza      | Matr. 1 | Padrao       | Total: R$ 2.000,00
Nome: Beatriz Alves     | Matr. 11| Comissionado | Total: R$ 2.900,00
                         (Comissao R$ 900,00 - 5% sobre R$ 18.000,00)
Nome: Thiago Nunes      | Matr. 14| Producao     | Total: R$ 3.500,00
                         (Bonus R$ 1.500,00 - 300 pecas x R$ 5,00)
--------------------------------------------------------------------------------
TOTAL DA FOLHA: R$ 8.400,00

Se nao houver funcionarios: "Nenhum funcionario cadastrado ainda."

================================================================================
 6. MENU ADMINISTRATIVO (acessado pela opcao [5] no perfil ADM)
================================================================================

--------------------------------------------------------------------------------
MENU ADMINISTRATIVO
--------------------------------------------------------------------------------
(1) - Exportar TSV e XLS
(2) - Importar arquivo TSV (substitui todos os dados)
(3) - Novo mes (arquiva atual e limpa a base)
(4) - Editar funcionario
(5) - Remover funcionario
(6) - Resetar sistema (com backup automatico)
(7) - Configuracoes do sistema
(8) - Editar funcionarios em lote (por tipo)
(9) - Abrir Dashboard Analitico
(0) - Voltar ao menu principal
--------------------------------------------------------------------------------

Abaixo, o comportamento esperado de cada opcao.

--------------------------------------------------------------------------------
 (1) - EXPORTAR TSV E XLS
--------------------------------------------------------------------------------

- Gera dois arquivos na pasta `exportados/` com data/hora no nome.
- Se houver erro de permissao, a mensagem e clara: "Falha ao gerar TSV/XLS".

--------------------------------------------------------------------------------
 (2) - IMPORTAR ARQUIVO TSV
--------------------------------------------------------------------------------

- Abre um seletor grafico de arquivos (se disponivel).
- Em terminal sem interface, pede o caminho manualmente.
- Substitui TODOS os dados atuais.
- Antes de importar, pergunta confirmacao (S/N).
- Cria backup automatico do estado anterior.

Validacoes possiveis:

   ERRO: Linha 3: tipo desconhecido 'GERENTE'
   ERRO: Linha 2: esperadas 11 colunas, encontradas 4

Importacao e cancelada automaticamente nesses casos.

--------------------------------------------------------------------------------
 (3) - NOVO MES
--------------------------------------------------------------------------------

- Arquiva a base atual na pasta `historico/`.
- Pergunta se deseja copiar os funcionarios (zerando vendas/pecas) ou limpar tudo.
- Exemplo:

   Deseja copiar os funcionarios do mes anterior (zerando vendas/pecas)? (S/N): >> S
   Deseja continuar? (S/N): >> S

   -> [OK] Historico salvo e base preparada para novo mes.

--------------------------------------------------------------------------------
 (4) - EDITAR FUNCIONARIO
--------------------------------------------------------------------------------

- Digite a matricula (0 cancela).
- Exibe dados atuais.
- Pergunta se deseja alterar o tipo do funcionario (Padrao/Comissionado/Producao).
- Depois, pede novo nome (ENTER mantem), e campos especificos do tipo.
- Validacoes de bonus (teto) e nomes semelhantes sao aplicadas novamente.

Exemplo de edicao simples (mesmo tipo):

   Novo nome: >> Carlos Pereira Souza
   Novo total de vendas (ENTER para manter): >> 22000
   -> [OK] Funcionario editado.

Exemplo de mudanca de tipo (Padrao -> Comissionado):

   Deseja alterar o tipo? >> 2 (Comissionado)
   Total de vendas: >> 12000
   Percentual: >> 6
   -> Tipo alterado e dados preenchidos.

--------------------------------------------------------------------------------
 (5) - REMOVER FUNCIONARIO
--------------------------------------------------------------------------------

- Digite a matricula (0 cancela).
- Mostra nome e tipo e pede confirmacao (S/N).
- Exemplo:

   Funcionario encontrado: Carlos Souza (Padrao)
   Confirmar remocao? (S/N): >> S -> [OK] Funcionario removido.

--------------------------------------------------------------------------------
 (6) - RESETAR SISTEMA
--------------------------------------------------------------------------------

- Apenas com confirmacao textual: digitar exatamente `CONFIRMAR`.
- Cria backup automatico antes de apagar todos os dados.
- Exemplo:

   Digite CONFIRMAR para prosseguir: >> CONFIRMAR
   -> [OK] Sistema resetado. Backup salvo em: backups/backup_....tsv

Qualquer outra entrada cancela a operacao.

--------------------------------------------------------------------------------
 (7) - CONFIGURACOES DO SISTEMA
--------------------------------------------------------------------------------

Exibe e permite alterar:

   * Salario base (ex: R$ 2.000,00)
   * Teto de bonus (% do salario base)
   * Limite maximo de matricula (0 = sem limite)
   * Modo de sequencia de matricula (RIGIDO ou FLEXIVEL)

--------------------------------------------------------------------------------
Exemplo de tela de configuracoes
--------------------------------------------------------------------------------
Salario base         : R$ 2.000,00
Teto de bonus        : 200,0% do salario base (R$ 4.000,00)
Limite max. matricula: Sem limite
Sequencia de matricula: FLEXIVEL (com aviso)

1 - Alterar salario base
2 - Alterar teto de bonus (%)
3 - Alterar limite maximo de matricula
4 - Alterar modo de sequencia
0 - Voltar
--------------------------------------------------------------------------------

Cada subopcao pede o novo valor e aplica validacoes simples (nao negativo, numerico etc.).

--------------------------------------------------------------------------------
 (8) - EDICAO EM LOTE POR TIPO
--------------------------------------------------------------------------------

- Escolha o tipo (Padrao, Comissionado, Producao).
- O sistema lista todos os funcionarios daquele tipo.
- Para cada um, pergunta: [E]ditar, [N]pular, [Q]sair.
- Se escolher E, entra no mesmo fluxo de edicao individual (opcao 4).
- Ao final, mostra quantos foram editados e pulados.

--------------------------------------------------------------------------------
 (9) - ABRIR DASHBOARD ANALITICO
--------------------------------------------------------------------------------

- Tenta abrir uma janela grafica (Java Swing) com graficos e estatisticas.
- O terminal continua disponivel enquanto a janela estiver aberta.
- Se o ambiente nao tiver suporte a interface grafica, exibe erro:

   [ERRO] Nao foi possivel abrir o dashboard.
   Detalhe: Can't connect to X11 window server

================================================================================
 7. MENSAGENS DE ERRO MAIS COMUNS (leitura numerica)
================================================================================

Situacao                                | Mensagem exibida
----------------------------------------|----------------------------------------
Menu: letra no lugar de numero          | "Inteiro invalido"
Configuracoes: valor nao numerico       | "Numero invalido"
Cadastro vendas/% : nao numerico        | "Numero invalido. Use virgula para decimais"
Cadastro vendas/% : valor negativo      | "Nao pode ser negativo. Digite novamente"
Cadastro pecas: nao numerico            | "Numero invalido. Digite novamente"
Cadastro pecas: negativo                | "Nao pode ser negativo. Digite novamente"

================================================================================
 8. PROBLEMAS NA INICIALIZACAO (database.tsv)
================================================================================

--------------------------------------------------------------------------------
DATABASE INEXISTENTE
--------------------------------------------------------------------------------
O arquivo database.tsv nao foi encontrado.
Contate o administrador do sistema.
-> Sistema encerra.

--------------------------------------------------------------------------------
ERRO CRITICO NA INICIALIZACAO
--------------------------------------------------------------------------------
ERRO AO LER database.tsv
Linha 4: esperadas 11 colunas, encontradas 3
Corrija o arquivo ou remova-o para recomecar.
-> Sistema encerra.

Se a linha #CONFIG estiver corrompida, um aviso e exibido, mas o sistema usa valores padrao.

================================================================================
 9. SAIR DO SISTEMA
================================================================================

No menu principal, digite 0.

   -> "Dados salvos. Volte sempre!"

Se houver falha ao salvar (ex: permissao de escrita):

   [AVISO] Falha ao salvar os dados!
   Os dados desta sessao podem ter sido perdidos.
   Verifique permissoes de escrita na pasta do sistema.

================================================================================
 10. DICAS FINAIS
================================================================================

- Perfil FUNCIONARIO nao enxerga o menu ADM (opcao 5 e invalida).
- Em qualquer campo de texto, digitar 0 (zero) cancela a operacao.
- Backups sao automaticos em importacoes, reset e novo mes.
- O sistema grava um log de operacoes (sem interromper o uso).
- O dashboard analitico abre em janela separada - feche-a para voltar ao terminal normalmente.
